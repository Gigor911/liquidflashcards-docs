# StatusPill

A small tinted-glass pill for a card's last rating or status: the `rating*Tint` fill with the matching `rating*Ink` label.

- **Use** on card detail and review history. Always a word, never a colour alone.
- Phase labels (New, Learning, Review, Due, Relearning) use the `phase*` colours.

_Static web rendition, hand-written from the SwiftUI source; the app component is SwiftUI._
