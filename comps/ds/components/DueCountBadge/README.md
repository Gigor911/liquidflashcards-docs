# DueCountBadge

The number of cards due, in `textOnAccent` on an `accent` capsule: 13pt bold tabular digits, 10×4 padding.

- **Use** only for due counts (rows, sidebar). Nothing else gets an accent capsule with a number.
- Numbers use the locale's grouping ("1,000", "1 000").
- Accessibility label reads "19 cards due".
- visionOS: white on the plum `controlTint`.

_Static web rendition, hand-written from the SwiftUI source; the app component is SwiftUI._
