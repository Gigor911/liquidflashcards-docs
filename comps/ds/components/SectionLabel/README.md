# SectionLabel

`GlassSectionLabel`: a small uppercase label above a glass group, 13pt bold, tracking 0.5, `textSecondary`, marked as a header.

- Write it in sentence case in code; the style uppercases it. Use a middle dot to add a count: "Due today · 6 decks", "Coming up · Next 7 days".
- An optional trailing accent link (14pt semibold, natural case) jumps to the full list.
- Inset 4pt from the card edge, 8pt above the card.

_Static web rendition, hand-written from the SwiftUI source; the app component is SwiftUI._
