# EmptyState

`GlassEmptyStateCard`: a 64pt icon tile, a 22pt bold title, a 15pt `textSecondary` message and one or two capsule actions, on a glass card (`radius-hero` 30).

- **Use** for first run, empty decks, no search results, stats with no history, nothing due.
- Say what's missing and the one next step; no blame, no exclamation marks.
- Actions stack vertically, or side by side where width allows (`actionsSideBySide`).
- **Consumer provides** `systemImage`, `title`, `message`, primary title + action, optional secondary.

_Static web rendition, hand-written from the SwiftUI source; the app component is SwiftUI._
